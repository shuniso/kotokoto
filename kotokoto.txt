# 音色。使いたい 1 行だけ # を外す（複数あれば最後の行が有効）。
# それぞれの音は samples フォルダーの同じ名前の WAV で聴ける。
#
#   f0        いちばん低い共鳴の高さ (Hz)。全体の高さが決まる
#   modes     共鳴の数
#   spread    いちばん高い共鳴が f0 の何倍か
#   loss      減衰しやすさ。大きいほど余韻が短い
#   contact   接触時間（ミリ秒）。短いほど硬く明るい
#   click_ms  接触音（カチッ）の長さ（ミリ秒）
#   click     接触音の量
#   click_hz  接触音の高さ (Hz)
#   touch     指がキーに触れる音の量。0 で無し。入れると本体が約 8 ミリ秒遅れる
#   release   キーを離したときの音の量。0 で無し
